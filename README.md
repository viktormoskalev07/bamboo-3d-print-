# bamboo-3d-print — Bambu Plotter

Студия для рисования ручкой (pen plotter) на 3D-принтере **Bambu Lab A1**.
Текст, таблицы, SVG и рисование мышью на одном листе → готовое задание `.gcode.3mf` → печать через **Bambu Connect** (вход по email, Bambu Handy продолжает работать) или с microSD.

Написано на Rust (egui). Windows.

## Возможности

- **Единый лист**: текст, таблица, SVG-рисунок и нарисованное мышью печатаются вместе; любой элемент можно перетащить мышью.
- **Однолинейный шрифт** (буквы одной линией, кириллица + латиница): латиница — Hershey Futura (public domain), кириллица дорисована в том же стиле. Также доступны шрифты Windows (рисуются контуром).
- **Таблицы**: редактирование ячеек, вставка из Excel, заголовок на каждой странице.
- **Рисование**: карандаш, линия, прямоугольник, круг, сетка с подписями в мм, привязка к сетке, выбор/перемещение/удаление фигур.
- **Превью = G-code**: превью строится разбором готового G-code — видно ровно то, что нарисует принтер. Стол A1 с линейками, анимация рисования.
- **Бумага**: A5, A6, открытка, квадрат, A4 (свисает со стола — раскладка только в зоне досягаемости ручки).
- **Калибровка**: подбор высоты ручки, тест направления, тест масштаба 100×100 мм и коррекция масштаба по X/Y.
- **Без нагрева**: G-code не включает нагрев сопла и стола, нет экструзии, отключены датчики филамента.
- **Горячие клавиши** как в Photoshop (Ctrl+Z/Y, Delete, Ctrl+C/V/D, стрелки, V/B/L/U/E/G, F1 — справка), в любой раскладке.
- **Автосохранение** настроек и документа при каждом изменении.

## Запуск

```
cargo build --release
target\release\bambu-plotter.exe
```

Настройки сохраняются рядом с exe: `plotter.toml` (бумага, ручка, скорость) и `session.json` (документ).

Для печати через облако установите [Bambu Connect](https://bambulab.com/en/software/bambu-connect).

## Настройка ручки

1. **Калибровка → Калибровка высоты ручки**: напечатайте лист, выберите Z с ровной линией.
2. **Смещение ручки** (X/Y относительно сопла) — в настройках ручки.
3. **Тест направления** — если отпечаток зеркальный, включите «Отразить по X/Y».
4. **Тест масштаба** — измерьте квадрат линейкой и введите результат в «Коррекция масштаба».

## Автоматизация и тесты

Приложение можно запускать в режиме автоматизации — для автотестов и управления агентом (Claude) через MCP:

```
bambu-plotter.exe --screenshot out.png --offscreen [--mode table]   # скриншот из командной строки
bambu-plotter.exe --automation 7878 --offscreen                      # локальный JSON API
target\release\plotter-mcp.exe                                       # MCP-сервер (stdio)
```

Тесты интерфейса (кликают кнопки, вводят текст, проверяют G-code):

```
powershell -File tests\ui_test.ps1
powershell -File tests\persist_test.ps1
```

Тестовые запуски используют отдельные настройки и не трогают данные пользователя.

## Структура

| Файл | Что делает |
|---|---|
| `src/app.rs` | интерфейс (egui) |
| `src/jobs.rs` | документ → страницы (раскладка элементов, фигуры) |
| `src/gcode.rs` | генерация и разбор G-code |
| `src/text.rs`, `src/hershey.rs` | шрифты (TTF и встроенный однолинейный) |
| `src/table.rs`, `src/svg.rs` | таблицы (CSV) и SVG |
| `src/output.rs` | упаковка `.gcode.3mf` (формат Bambu Studio) |
| `src/connect.rs` | отправка в Bambu Connect |
| `src/printer.rs` | отправка по LAN (FTPS + MQTT, нужен Developer Mode) |
| `src/auto.rs`, `src/bin/plotter-mcp.rs` | автоматизация и MCP-сервер |
| `templates/a1/` | метаданные 3MF для Bambu Lab A1 |
| `assets/futural.jhf` | шрифт Hershey Futura (public domain) |
